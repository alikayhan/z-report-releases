# Z Report has moved

Z Report is now developed and released from
[github.com/alikayhan/z-report](https://github.com/alikayhan/z-report). Every release
that used to live here is available there too, under the same tags.

- Download: https://github.com/alikayhan/z-report/releases/latest
- Homebrew: `brew install --cask alikayhan/tap/z-report`
- Claude Code mod:

  ```sh
  claude plugin marketplace remove z-report
  claude plugin marketplace add alikayhan/z-report
  claude plugin install z-report@z-report
  ```

Installed apps update to the new location on their own. This repository is archived and
kept only so older download links keep working.
